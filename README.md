# Simple Stopwatch ⏱️

A clean and minimal **React Stopwatch** built with Hooks.

Perfect for learning `useState` and `useEffect` with intervals.

## ✨ Features

- Start, Stop, and Reset functionality
- Real-time second counter
- Clean and simple UI
- Proper cleanup of intervals to avoid memory leaks

## 🖼️ Preview

- Displays the number of seconds elapsed
- **Start** → begins counting
- **Stop** → pauses the timer
- **Reset** → stops and sets the counter back to 0

## 🚀 How to Run

1. Create a React project (or use an existing one)
2. Replace the content of `App.js` (or `App.jsx`) with the provided code
3. Start the development server:

bash
npm start
# or
npm run dev

## 🛠️ Tech Stack

React (Functional Components + Hooks)
useState for timer state
useEffect for handling the interval
